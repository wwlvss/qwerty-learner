# Qwerty Learner 本地学习包

这是构建好的网站，不需要下载源码、安装项目依赖或重新构建。服务器只监听本机。

## Windows

1. 将整个 ZIP 解压到一个普通文件夹（例如桌面），不要直接在 ZIP 中启动。
2. 双击 `start-windows.cmd`，保持命令窗口打开。浏览器会打开 http://localhost:4173 。
3. 没有 Node.js 时，首次启动会从 nodejs.org 下载便携版 Node.js 24，并校验 SHA256；需要联网，无需管理员权限。已有 Node.js 20.19+ / 22.12+ / 24 时直接使用。
4. 下载失败时，可以从 https://nodejs.org/ 安装 LTS 版本后重试。若系统或公司策略禁止脚本/程序运行，使用网页版，不更改系统策略。
5. 关闭命令窗口会停止网站；下次运行同一文件即可。端口被占用时，先关闭上一次启动的窗口。

## macOS / Linux

安装 Node.js LTS 后，在此文件夹运行 `sh start-macos-linux.sh`，或 `node server.cjs` 后打开 http://localhost:4173 。

## 数据从网页版迁移

- 网页版设置 → 数据备份 → 导出全部学习数据（`.gz`）。
- 在本地网站的同一入口导入；完整导入按原项目语义覆盖已有记录，先导出备份，在新本地地址上首次导入最简单。
- 只迁移不熟词和备注时，可在“不熟词本”导出 JSON，再在本地导入，按词形合并，不删除其他收藏。
- 记住章节选择等浏览器偏好不在完整数据库备份内，需要重新选择。
- 数据存在浏览器 IndexedDB，不在解压目录里。始终使用相同浏览器、用户配置和 `http://localhost:4173` 地址；换成 127.0.0.1、改端口、隐私窗口或清理站点数据都会影响可见数据。
- 更新软件时先导出学习数据，再解压新包；不要把清理浏览器数据当作更新步骤。

## 离线与内容扩展

静态页面、内置词库、内置短语和例句可由本机服务器读取，收藏和记录在本地保存。发音、外链及原项目的统计请求仍可能联网；本包不代表已有离线音频或已关闭所有统计。

本地部署不会自动补齐全词库解释。现有入口可导入词条、用法和可靠词源数据包；ECDICT/Tatoeba 的完整数据仍需整理接入，历史词源需要逐条有证据。新增或修改内置内容需要使用源码工具重新生成数据并构建。全部功能不要求付费 API。
