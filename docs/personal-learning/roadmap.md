## 建议下一轮顺序

1. 按工作英语、农业专业英语最高优先级扩充内容，再补日常、商务和考试词库。扩大数据覆盖：先固定 ECDICT 和 Tatoeba 版本，优先补个人词典及 CET 高频词，保留来源和真实覆盖率。
2. 例句填空：用本次保存的准确字符区间做练习，记录回忆、提示与答案显示，避免只记录抄写。
3. 句子输入与学习会话：增加完整句子模式、暂停/恢复、词典版本和章节快照。
4. FSRS：在有意义的回忆型练习上接入，抄写或阅读词源不自动增加复习次数。
5. 薄弱分析与离线交付：根据真实学习日志生成可解释建议，完善备份、PWA、音频及隐私开关。

不建议现在一次性重构，或为了追求“全覆盖”自动编造词源和模板例句。优先让数据接入、练习、记录、复习形成可验证的小闭环。
