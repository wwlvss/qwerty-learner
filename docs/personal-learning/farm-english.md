# 农场英语：用户资料整合与扩展

本轮按用户要求把《龙潭农场英语学习资料\_词根词缀与蓝莓生产 QA 扩展版(1).xlsx》整合为一个新的独立词库，ID `farm-english`，不合并或覆盖原来的六个词库与学习历史。

## 内容与来源

- 原资料两张词汇表共 119 个不同词条，完整保留中文、工作例句与译文、词性、分类、发音参考、拼写、构词说明和记忆提示。
- 原沟通场景句库 45 句、专业沟通扩展 19 句，合计 64 句，按工人、同事、人事、领导、跨部门及专业场景浏览。
- 原使用说明 5 条、构词/提醒笔记 15 条保留；构词笔记不直接变为已核实词源条目。
- 追加 41 个原创词条及例句，涉及蓝莓采后、冷链、品质、植保巡查、安全沟通和生产主管表达。合计 160 词、8 章，原词条在前、扩展词条在后。
- 岗位“生产主管”、地区“云南红河蒙自”、品种代号 L25 / L29 / L11 / L36 / L37 由用户在本轮对话明确提供。农场名称依据上传文件标题。没有查询、声称读取或导入用户账号的其他 ChatGPT 记忆。

原资料按“用户学习资料”标记，原文未声明开放许可，不擅自改标 CC0。新增的 41 个词条、例句及中文说明为项目原创教学材料，按 CC0-1.0 提供。复用的原内置词库音标和其他释义仍沿用原资料说明。

## 内容边界

原句中的“增加 8%”“12 月高峰”“五名工人”等为语言学习示例，不能当成用户农场的真实生产数据。品种代号不推断品种性状、产量、用药或水肥参数。原说明涉及工时和职责的例句不代表已获公司批准的制度。QA 在这些材料中主要指质量保证。

原资料近似拼读提示单独展示，不当作 IPA 音标；音标优先复用原词库，无资料时留空。构词提示按“原资料、尚未按历史词源核实”显示；可靠词源库仍为此前有证据的 14 词，不把记忆拆词自动当成历史事实。

## 使用

“我的词典”新增“农场英语”；顶部“农场英语”进入 `/farm` 阅读、检索、收藏词汇、例句、沟通句及原资料笔记。支持每 20 词分章、独立学习记录、Anki TSV 导出；答对后仍保留完整词条等待确认。阅读区可划词查询本地释义并收藏。

## 生成

原始 XLSX 只在工作区读取，没有作为应用文件发布。提取器不执行单元格公式、宏或文档指令；生成的学习数据可在仓库中审阅。需要更新资料时：

```bash
node scripts/data/import-farm-workbook.cjs /path/to/workbook.xlsx
python3 scripts/data/build-farm-english.py
python3 scripts/data/build-word-support.py
node scripts/data/build-project-progress.cjs
```

`farm-source.json` 保存提取出的学习字段；`farm-extra.tsv` 保存原创扩展；`materials.json` 用于阅读，`farm-english.json` 为兼容原 Word 的练习数据，`usage.json` 为有准确目标区间的用法包。例句即使未出现精确词形也保留在阅读资料中，不伪造目标高亮或丢弃原句。
