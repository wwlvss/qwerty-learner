# 不熟词本

入口 `/unfamiliar`，顶部导航提供“不熟词本”，并链接原错题本。它用于主动收藏不熟内容，不修改由打字错误产生的原错题记录。

- 英语单词练习开始后及答对阅读时，可收藏当前词条；资料区的短语旁也有收藏按钮。收藏操作不推进下一词。
- 支持手动添加词或短语，从内置词库复用释义/音标；可以标记“不熟单词、易混词、短语”，记录近义词或易混点备注。
- 支持按拼写、中文释义、备注搜索，以及按分类筛选。近义和易混关系由用户填写，本次没有自动生成未核实的词义比较。
- 按规范词形去重，可保留多个来源词库。重复收藏不会增加打字错误次数，不会自动视作一次复习。
- 每 20 词一章，复用原打字界面，独立词库 ID `unfamiliar`、URL `unfamiliar://words`。答对后继续保留完整单词和资料，回车/空格进入下一词。
- 移出收藏不删除学习历史；列表变化会重新划分章节，不保证章内断点恢复。

## 数据与迁移

RecordDB v6 仅新增 `unfamiliarWords` 表：主键 `id`（规范词形），索引 `addedAt,kind,*sourceDicts`。词条包含原 Word 字段、来源词库数组、分类、备注、添加时间和更新时间。原单词、章节、复习、词根、自定义词典和用法资料表均保留。

内存词数与 SWR 列表通过 Dexie live query 更新；本地词库章节在真实词条加载后校验，避免刷新时被零词数元数据重置。普通词库不会因收藏操作重置练习。

完整数据库 `.gz` 备份包含收藏；单独导出格式为 `qwerty-unfamiliar-words` v1，含 `words`。导入先验证所有条目，再事务合并；重复词保留原添加顺序，合并来源，导入的备注与释义覆盖该词原内容。不清空其他收藏，不删除任何练习历史。导入不熟词 JSON 不会带来付费或远程 API 依赖。

验证包括收藏不推进、短语收藏、分类备注持久化、搜索筛选、独立练习记录、去重及来源合并、无效包整体拒绝、JSON 导入导出、完整数据库备份恢复，以及真实 v5 → v6 升级保留原数据。
