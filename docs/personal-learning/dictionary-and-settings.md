# 多义词释义与个人学习界面

场景词库不能以一个场景义替代单词的其他常见意思。本次继续使用现有免费本地词库，不安装依赖、不接入付费 API。

## 保留释义

四个主题词库的 Word 数据增加可选 `contextTrans` 数组，单独保留当前场景重点。`trans` 汇总原内置词库中的中文释义（精确文本去重），原有释义和原词库文件不删除、不重写。按键练习前后，上方显示场景重点；答对后“词典释义”展示其他解释，并允许展开全部条目及来源。

例如 nursery 在农业场景显示“育苗场；苗圃”，`trans` 同时保留原词库中的“托儿所、保育室、育婴室、温床”等解释。词库里的词仍为 nursery，不将用户提问中的 nusery 当成正确拼写。

`build-word-support.py` 从 316 个英语词库汇总中文释义，发布为 `public/data/word-support/definitions/` 的双字母分片。当前 40547 个不同词条有中文释义汇总。来源保存词库 ID，可通过现有资源映射追溯原文件。重复或措辞接近的释义保持原样，不声称自动完成了词义消歧或权威词典全义项核实。英英解释、例句或其他语言的翻译不冒充中文义项，原文件中仍保留。

前端只读当前词形所在分片，按构建版本更新缓存。某片读取失败时，仍展示 Word.trans 中已有释义；不会自动跳词。收藏与个人词典导入支持至少 100 条释义，新增 contextTrans 也需验证，避免导出后再导入时丢失多义项或读取非法数组。

## 界面

默认简洁布局使用文字“设置”和“更多工具”，低频音效、循环、默写、释义开关、统计、指法图等工具收在“更多工具”里，原快捷键仍注册。关闭简洁布局可恢复常驻工具及原页脚。个人页默认隐藏社群、赞助等图标和章节完成时的捐赠卡，不删除相关原功能。

Logo 返回本系统首页；练习页允许随阅读内容纵向增长。答对后的资料按“词典释义 / 短语例句”双栏组织，在较窄窗口中自动单栏。上方完整单词继续保留，回车或空格释放后才进入下一词。

## 个人学习设置

设置默认打开“个人学习”页，提供：简洁界面、其他释义、短语、例句、词根词源、自动单词发音、英美音、键盘音效、正确/错误提示音、深色模式。既有音效、高级、显示、数据设置页保留，可调整字体、默写、循环、乱序和备份。

显示偏好存入浏览器 `learningPreferences`；既有音效和发音继续使用原配置。隐藏资料不删除数据、不修改收藏或历史，也不改变答对后等待确认的流程。显示偏好与原章节选择一样，不在完整 IndexedDB 数据备份中。数据库仍为 v6，不需要表迁移。
