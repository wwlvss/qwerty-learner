# 手机入口与本站导航

原项目会把宽度不超过 600px 的访问强制重定向到 `/mobile`。旧页面是作者宣传页，官网、首页和开始学习等链接指向 qwerty.kaiyi.cool；它不是个人学习系统的手机界面。

本次移除按窗口宽度强制重定向的路由分支。手机和电脑使用同一套学习页面，直接访问词库、不熟词本、自定义词典和词根 URL 不再被拦截。旧 `/mobile` 入口保留为跳转本站 `/my-dictionary` 的兼容入口，删除旧宣传页和其中的作者官网导航。原词库、词源的资料引用与许可不变。

同时移除 resize 时直接设置 `window.location.href='/'` 的旧逻辑，避免横竖屏或窗口尺寸变化丢失当前路径、离开 GitHub Pages 的项目子路径。Logo 仍通过 React Router 返回本站首页。

小屏改进包括：导航换行与边距、设置面板宽度和侧栏、练习统计区宽度、长单词/短语换行。电脑端的词库、收藏、释义、Anki 导出、输入及历史记录复用原实现。

手机可查看词库、收藏、备注、短语例句与词根，导出资料；手机与电脑的浏览器记录不会自动同步，可通过原有备份迁移。当前打字练习仍依赖键盘按键，尚未实现手机软键盘输入适配，手机页面明确提示需要外接键盘。不能因修正入口而声称原生触屏输入已完成。

验证使用 Chromium 的 390×844、触屏、手机 UA 模拟，涵盖旧入口、站内导航、收藏持久化、外接键盘等价按键输入、窗口旋转/尺寸变化、长短语和设置布局；另做 GitHub Pages 子路径生产包检查。未在真实 iOS/Android 设备上完成实机验收。
