# 阅读选词、近义表达与语速修复

## 文字选择与本地查询

原全局 `body { user-select: none }` 使答对后的资料也不能正常选择。现在仅阅读区及其子元素恢复 `user-select:text` 与 WebKit 对应属性，输入区继续保留原设置。阅读区支持鼠标拖选、键盘选择和浏览器复制。

选择英文后浮层查询：页面中已配对的词/短语/整句译文、个人词典、不熟词本、原词库及汇总释义。都在本地资料与 IndexedDB 中查询，不把选中文字发送到外部翻译服务。未知表达明确显示缺失，可补中文后收藏；没有实现任意整句自动翻译。收藏时合并已有释义、保留来源和原备注。

拖动选择期间不弹出浮层，避免打断选区；浮层在松开后出现，可关闭或点空白处收起。有选区时回车/空格不自动推进，复制不会变成一次练习或复习；关闭选词并清除选区后恢复原确认下一词规则。

## 近义词与近义表达

首批原创教学资料 32 组、70 个不同词或表达，其中 61 个出现在当前内置词条索引中。覆盖培训、工作安排、检查、维修、工时、采收、灌溉、采购和礼貌沟通。组内明确语境与差别，不声称同义表达可无条件替换，也不声称这些是权威词典或 WordNet 导出。

答对后显示近义区，可划词或直接收藏近义表达，设置中可关闭。未覆盖的词显示缺失状态。资料源在 `scripts/data/synonyms.json`，由 `build-word-support.py` 生成发布数据。逐条扩大词典核对和个人易混专项练习仍在待办中。

## 音标与实际播放速率

移除音标前的 AmE/BrE 标签，音标本身保留，英美音由原发音选项切换。

原 `use-sound` 调用传入 `rate`，但库用于更新速率的选项是 `playbackRate`。现在传正确字段，并在配置或已加载 sound 变化时调用 `sound.rate` 同步。原音效设置滑块改为受控值，个人学习设置提供倍速选项，两处共用原持久化配置，不升级依赖。

浏览器使用本地产生的测试音频拦截有道请求，检查真实 HTMLMediaElement.playbackRate 从 1 到 0.5、2 的变化及刷新后的新播放器速率；不只测试设置值。实际发音仍使用原有网络音频服务，未交付离线音频。
