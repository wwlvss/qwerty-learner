# Anki 兼容导出与默写译文

六个独立学习词库的卡片、“自定义词典”和“不熟词本”都提供 Anki 导出按钮。生成 UTF-8 `.tsv`，三列为 Front、Back、Tags，适用于 Anki 桌面版基础卡片。

1. 在 Anki 中选择“文件 → 导入”，选择导出的 TSV。
2. 选择基础卡片（Basic，或当前语言中的同类正面/背面笔记类型），选择目标牌组。
3. 核对分隔符为 Tab、允许字段中有 HTML；Front 对应正面，Back 对应背面，Tags 对应标签。较新 Anki 可识别文件头的列/HTML/标签设置。
4. 导入前检查重复笔记的处理方式，尤其是不同词库中存在相同拼写时；不要无意更新已有个人笔记。

正面为单词或短语；背面包含当前可读取的场景释义、原词库多义解释、英美音标、短语和例句（保留资料说明）、个人备注及来源词库。标签包含词库 ID、收藏来源和易混词/短语等分类。HTML 特殊字符转义，字段内换行转为 `<br>`，Tab 转为空格，避免备注破坏字段边界或变成可执行 HTML。

这是文本笔记导入格式，不是 `.apkg`。不打包发音文件，不同步本网站学习历史、到期日或 FSRS 状态。Anki 中的复习安排由 Anki 自己管理。可用资料读取失败时，仍保留词条自带释义，缺失内容不自动编造。已验证 TSV 的字段、编码、HTML 转义及浏览器下载；未在当前 Linux 环境安装 Anki 桌面客户端执行导入。

## 默写中的中文译文

设置 → 个人学习 → “默写时隐藏中文译文”默认开启。默写时单词和短语的主释义、悬停/Tab 临时释义及侧边词表中文均不提前显示；输入正确后才显示释义和资料，仍需回车或空格进入下一词。关闭此选项可恢复中文提示，适合看中文回忆英文。

此修复不删除词条翻译或用法资料，不把“隐藏译文”当作修改原词库。已有默写类型、快捷键及原设置继续保留。
