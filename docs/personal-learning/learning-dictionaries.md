# 六个独立学习词库

“我的词典”入口 `/my-dictionary` 展示六个分开的词库，每个有自己的词库 ID、章节选择和学习统计，不合并成一个个人生词本。

| 词库         | ID                  | 首期词条 | 优先级 | 内容                              |
| ------------ | ------------------- | -------- | ------ | --------------------------------- |
| 工作英语     | work-english        | 60       | 最高   | 工作沟通、任务安排、进度汇报      |
| 农业专业英语 | agriculture-english | 80       | 最高   | 种植、土壤、灌溉、水肥、植保      |
| 日常英语     | daily-english       | 40       | 高     | 日常交流、生活表达                |
| 商务英语     | business-english    | 40       | 中     | 会议、邮件、采购、协调            |
| CET-6        | cet6                | 2345     | 中     | 沿用原 CET6_T.json                |
| IELTS        | ielts               | 3575     | 后续   | 沿用原 IELTS_3_T.json，可随时练习 |

四个新词库各有独立的 `public/dicts/{id}.json`，兼容原 Word 数据格式，无新运行时依赖。CET-6 和 IELTS 沿用原 ID、原文件，已有学习记录继续可用。四个主题词库是首期精选内容，需要逐步扩充，不能视作完整专业词典。

农业专业英语每章 20 词：第一章种植与作物；第二章生育、土壤与栽培；第三章灌溉与水肥；第四章营养监测与植保。教学例句用于英语学习，不提供农药剂量等操作建议。

## 短语与例句

四个新词库的 220 个词条均配有一组场景搭配、例句及中文译文，保留目标词 UTF-16 区间。同词可在多个词库出现，例如工作与商务的 meeting；短语和例句带可选 `context` 字段，界面优先显示当前词库对应场景。

这些中文释义、搭配、例句和译文由本项目编写，按 CC0-1.0 提供；属于原创教学材料，不冒充 Tatoeba 原句、语料频率统计或历史词源证据。音标从原词库复用，没有匹配的保留空白，不编造音标；原音标的来源许可仍适用。

可编辑来源为 `scripts/data/learning-dictionaries.tsv`，每行包含词库 ID、词条、释义、搭配、搭配译文、例句、例句译文。修改后依次生成：

```bash
python3 scripts/data/build-learning-dictionaries.py
python3 scripts/data/build-word-support.py
```

生成器检查每个词库数量、词库内重复和例句目标匹配；词条顺序决定章节。重复生成使用原基础词库音标，不循环读取生成文件。

## 本地进度与兼容

复用原 `wordRecords`、`chapterRecords`、`reviewRecords` 表，以 `dict` 字段区分六个词库，保持原错题与分析功能。章节选择通过 `learningDictionaryChapters` 本地保存，每个词库各自记忆。此处记忆的是章节，不是章内逐词断点恢复。完整数据库备份包含学习记录；章节选择与原 currentChapter 一样属于浏览器偏好，不在数据库备份中。

原 `personal` 词库仍保留，界面改名为“自定义词典”，入口 `/my-dictionary/custom`，原添加、导入、导出、复制词库功能继续可用；不会迁移或删除旧词条。数据库保持 v5，无需为六个静态词库增加表或升级版本。浏览器清理站点数据仍会清除本地记录，建议定期导出。
