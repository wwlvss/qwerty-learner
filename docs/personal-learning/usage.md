# 短语、例句和自定义词典

## 当前已实现

答对任何英语词条后，完整单词保留在上方，下方自动显示短语、例句和词源。只有回车、空格或“下一个词”才推进，资料加载不控制练习队列。此流程也适用于个人新词。正确率随按键立即更新，避免不足一秒就进入阅读时因暂停计时而仍显示旧正确率；错误按键从状态 updater 外报告一次，修复 StrictMode 下的重复计数，已有数据库记录不重写。

“我的词典”现在是六个独立学习词库的入口，详见 [learning-dictionaries.md](learning-dictionaries.md)。原个人词典保留在 `/my-dictionary/custom`，改名为“自定义词典”，ID 仍为 `personal`，不是收藏或错题列表。它支持单词/短语添加、搜索、移除、文本批量添加、JSON/TXT 导入、JSON 导出，以及复制一个现有英语词典。每 20 词一章，章节、逐词记录、错题和原有分析继续使用原系统，以 `dict=personal` 与其他词库分开。

添加单词或批量导入时，默认从原有词库索引查找并复用释义与音标；用户手填释义优先。没有找到时保留用户输入，明确显示未填释义，不自动编造。索引仅存原文件 URL 和位置，没有再复制一份完整基础词典。

## 功能覆盖与资料覆盖

所有英语词条使用统一的资料查询入口，并不代表所有词都有完整资料。当前分片索引来自 316 个内置英语词库的全部本地文件，合并去重后为 42,821 个词条。

- 15,509 个词条有原词库关联短语或原创搭配。
- 528 个不同词条有原创教学例句和中文译文，包含默认第一章全部 20 词及四个新主题词库的全部 480 个词条。
- 14 个词有此前逐条核对过的历史词源。
- `ket`、`Yilin1`、`Yilin2`、`Yilin3` 原来使用相对路径；已统一成与其他词库一致的路径，纳入索引。没有缺失的内置英语词库文件。

界面始终显示缺失状态，不使用随机模板句或拼写相似性去补齐词源。新增个人词典的单词可以通过本地用法数据包补充资料，不必修改原始词库。

## 来源与许可

`public/data/word-support/authored.json` 为本项目原创教学搭配、例句和中文译文，按 CC0-1.0 提供。它们不是 Tatoeba、词典或其他语料库的引文，也不是历史词源证据。此处“常用搭配”表示教学用途，不表示经过语料频率排名。

自动索引的短语来自仓库原有英语词库中含空格的词条，保留原词库名称、原 JSON 路径和原中文释义；按完整词元匹配，不做子串匹配（例如 he 不匹配 the）。这些词库原来的来源和许可说明继续适用，没有将所有原词库资料重新标成 CC0。它们在界面中单独标为“原词库资料”，不声称是已核实的高频搭配。

Tatoeba 原句需要从合法导出文件取得，保留句子 ID、贡献者归属、原词条链接和实际数据许可。本次环境访问 `downloads.tatoeba.org` 返回代理 403，未下载、冒称或批量复制其真实语料。ECDICT 也尚未正式导入，它不是现成例句或完整词源库。

## 数据与备份

RecordDB 逐步增量升级到 v6，旧表、旧词根收藏和学习记录不清理。

| 表               | 主键与索引                        | 内容                                               |
| ---------------- | --------------------------------- | -------------------------------------------------- |
| personalWords    | id（规范词形）、addedAt、position | 与原 Word 兼容的词条，保留添加顺序                 |
| wordUsageEntries | normalizedWord                    | 用户导入的短语、例句、中文译文、目标字符区间及来源 |

内置资料以字母分片发布，不会在页面启动时加载全部 14 MB。当前词库 context 匹配的场景资料优先显示，同场景下用户导入资料优先于内置资料，保存在 IndexedDB。完整数据库 `.gz` 备份会包含两张新增表；“导出自定义词典”只导出词条，便于像原词库 JSON 一样复用，不含学习历史。词根专用备份仍只管理词根模块。

个人词典导入采用按规范词形合并，更新已有词时保留原顺序，添加新词时追加。移除词条不删除历史记录。更改词表后，章节会按当前列表重新划分，因此长期的章节统计需要后续引入词典版本/章节快照；当前逐词历史仍保留原词形和字典 ID。目前提供六个固定的独立学习词库，另保留一个可编辑的自定义词典；尚未支持任意创建多个命名词典。

## 资料生成与扩展

重新生成原词库引用索引、短语分片和覆盖统计：

```bash
python3 scripts/data/build-word-support.py
```

用法包：`qwerty-word-usage` v1，entries 内含 normalizedWord、phrases、examples。例句必须包含与完整目标词一致的 UTF-16 字符区间，不能把 he 从 the 中挖出。来源、许可、纯文本长度和引用链接在导入前校验；无效包整体拒绝，不部分写入。示例格式见 `public/data/word-support/authored.json`。

本地 Tatoeba 导出预处理：

```bash
python3 scripts/data/prepare-tatoeba-usage.py \
  --sentences /path/to/eng_sentences.tsv \
  --words /path/to/selected-words.txt \
  --license '填写所选导出文件的真实许可及归属' \
  --output-dir /path/to/new-usage-packs
```

工具流式读取英文 TSV，按完整词元或最长 6 词短语的准确区间匹配目标，每词最多选 2 句，每包 2000 词。没有命中的词不生成占位假句，也不自动生成中文译文或声称句义核实。包可在“自定义词典”页面导入。

## 验证与限制

专用 Chromium 回归涵盖原打字、个人词典添加/导入导出/章节/去重/持久化、资料匹配与错误包拒绝、完整备份恢复，以及真实 v3 → v6、v4 → v6、v5 → v6 迁移。Python 测试检查词元匹配、例句高亮和覆盖报告对应实际分片。

无付费 API、无新运行时依赖、无管理员权限要求。网站整体仍未实现 Service Worker 离线冷启动；IndexedDB 中的个人词典和导入资料本地保存，但应定期导出备份。

最终检查：40 项 Chromium 回归和 8 项 Python 数据测试通过；构建和修改代码的 lint/格式检查通过。全项目类型检查仍仅有原来的 4 处 TS2339 错误，没有新增类型错误。

新增不熟词收藏、分类、备注与练习说明见 [unfamiliar-words.md](unfamiliar-words.md)。同样文本的短语/例句按当前场景优先后去重展示，减少重复。

词库文件、查询索引和短语/例句分片 URL 携带构建版本，避免发布后继续读取浏览器中旧词数/旧资料的缓存。
